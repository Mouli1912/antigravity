A modern productivity web app that combines smart todo management, habit tracking, streaks, gamification, focus tools, and productivity analytics in a futuristic interactive UI.

* Smart Todo Management
* Habit Tracking

* XP & Level Gamification

* Notifications & Reminders
* Responsive Modern UI
